### Who I am

**Embedded & systems engineer** building from bare-metal firmware to production web products.  
I ship **high-reliability IoT/IIoT devices** and **Persian RTL platforms** used in industry, logistics, healthcare, and surveillance.

Currently at **TrendHorizon / Pars Pardaz** — bridging hardware, edge gateways, and operator-facing software.

```text
 silicon ──► RTOS firmware ──► edge gateway ──► APIs & dashboards ──► operators
```
