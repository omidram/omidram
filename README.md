I take a system from the pin to the person on shift: the MCU or camera, the firmware, the gateway, then the screen. The rooms are plants, airports, fleets, clinics, and buildings. When the floor speaks Persian, the product does too — right to left, on a Jalali calendar, with the workflow the last shift already knew.

At **TrendHorizon / Pars Pardaz** that means hardware, the edge, and the operator software in one line of delivery.

| | |
| --- | --- |

| **Interface** | Bilingual EN/FA, Jalali dates, a shift that can finish the task |
| **Vision** | OpenCV, ONNX, and YOLO where the site can actually run them |
| **Delivery** | CMake, PlatformIO, Docker, GitHub Actions, modules with tests |
